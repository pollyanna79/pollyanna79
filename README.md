📊 Sistema Dinâmico de Gestão de Estoque  (Full-Stack)
Uma aplicação moderna e totalmente dinâmica que integra uma interface rica em componentes React com um ecossistema robusto de Engenharia de Dados no MySQL. O foco principal deste projeto foi a otimização de performance através de inteligência computacional aplicada direto no banco de dados e a garantia de alta fidelidade na sincronização de dados de produtos em tempo real.
🛠️ Stack Tecnológica:
Front-end: React.js, Tailwind CSS (Design Responsivo & Adaptável)
Banco de Dados: MySQL (Hospedagem Remota / Cloud)
Ferramenta de Modelagem: MySQL Workbench
Gerenciamento de Estado & Conexões: Hooks Avançados (useEffect/useState) e APIs de Integração Segura (Ponte de Conexão Dedicada).
🏗️ Arquitetura do Projeto & Destaques Técnicos:
O projeto foi construído seguindo os mais altos padrões de desenvolvimento atuais, dividindo-se em duas grandes frentes: Engenharia de Dados & Inteligência no MySQL
Em vez de sobrecarregar a aplicação React com processamento pesado, a inteligência e as regras de negócio foram centralizadas diretamente no motor do banco de dados:

Views Complexas: Criação de visões estruturadas (como a de mapeamento de assentos e estoque disponível) que realizam múltiplos JOINs internos, entregando dados limpos e prontos para o consumo do front-end.

Triggers (Gatilhos): Automação nativa para garantir a integridade dos dados. Sempre que uma nova compra é efetuada, o estoque ou status do pedido é atualizado instantaneamente sem necessidade de requisições manuais duplicadas.
Stored Functions & Procedures: Métodos customizados criados dentro do MySQL Workbench para encapsular lógicas repetitivas e cálculos matemáticos complexos de estoque.

Ponte de Conexão Remota: O banco de dados foi hospedado em um servidor em nuvem independente. Foi configurada uma nova conexão de rede dedicada, realizando o tunelamento e trâmites de segurança necessários para que a aplicação React dialogue com o banco remotamente de forma veloz e segura.

🚀 Funcionalidades Principais:
Sincronização Dinâmica de Inventário & Ofertas: Renderização em tempo real do status de produtos, níveis de estoque e campanhas promocionais consumidos diretamente através de Views otimizadas no MySQL. A interface conta com reatividade automatizada, desabilitando componentes visualmente e bloqueando interações de compra assim que o estoque de um item é zerado no banco de dados.

Fluxo de Compra Seguro: Validação de formulários e gerenciamento de transações que atualizam o banco de dados de ponta a ponta.

Tratamento de Concorrência: Proteção contra atualizações simultâneas graças às regras de integridade do MySQL.
